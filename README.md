# Esame Frontend 2

Questo è il repository del mio esame per il modulo Frontend 2 (React + TypeScript). 

## Cosa serve:
- **Node.js** Installato
- Una **API Key di TMDB** (The Movie Database). Se non ce l'hai, la puoi generare gratuitamente in due minuti dal loro sito ufficiale.


## Come montare il progetto:

### 1. Clona il repository:
Scarica il codice e posizionati nella cartella del progetto.

### 2.Scarica le dipendenze:

npm install

### 3. Configura le chiavi:

Crea un file chiamato esattamente .env nella root del progetto (allo stesso livello del package.json).

Incollaci dentro la tua chiave TMDB usando il prefisso di Vite. Ad esempio:

Snippet di codice
VITE_API_KEY=incolla_qui_la_tua_chiave_personale

### 4. Accendi i motori

npm run dev
